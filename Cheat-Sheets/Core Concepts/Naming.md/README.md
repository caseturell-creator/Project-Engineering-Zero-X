# Naming

## Technical Definition

A name is an identifier that allows humans or systems to refer to a resource without needing to know its physical location or implementation.

---

## My First Thought

IP addresses are like real digital destinations.

Websites are like people living in houses.

One day Google might live in one house, but tomorrow it might move into a condo in a different city.

DNS lets me keep saying "Google" while it quietly figures out where Google lives now.

---

## Refined Engineering Version

DNS separates identity from location.

The name stays the same.

The destination can change.
