# Identity vs. Location

## Definition

A system should separate what something is from where it is located.

---

## My First Thought

Google can move to another house, but I still type "google.com."

---

## Refined Understanding

Separating identity from location allows resources to move without affecting the people or systems that use them.

---

## My Analogy

A person can move to another house without changing their name.

DNS works the same way.

---

## Real World Example

Yesterday:

google.com → Server A

Today:

google.com → Server B

Users continue typing "google.com."

DNS handles the change behind the scenes.

---

## Why It Matters

Separating identity from location allows systems to move, expand, or change without affecting the people or software that use them.

This provides flexibility, simplifies maintenance, and allows services to grow without changing how users access them.
