# Hierarchy

## Definition

A hierarchy is a way of organizing information or responsibilities into different levels, where each level has a specific role.

---

## My First Thought

Instead of one computer knowing everything, each level only needs to know a small part of the system.

---

## Refined Understanding

A hierarchy breaks a large problem into smaller, organized pieces. Each level is responsible only for its own portion, making the system easier to manage, maintain, and scale.

---

## My Analogy

Finding someone's house.

Canada

↓

Province

↓

City

↓

Street

↓

House

Each level only needs to know the next step.
