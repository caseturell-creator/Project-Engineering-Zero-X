# Engineering Principles

This folder contains the core ideas and ways of thinking that I discover throughout Project Engineering Zero.

## Purpose

- Capture engineering concepts that apply across many technologies.
- Understand *why* systems are designed the way they are.
- Record lessons that change how I think.

## Structure

Each principle will have its own Markdown file.

Examples:

- Headroom
- Resource Allocation
- Layers of Abstraction
- Trade-offs
- Virtualization
- Containers
- Networking Concepts
