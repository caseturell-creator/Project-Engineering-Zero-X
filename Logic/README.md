# 🧠 Logic

## Purpose

This folder contains the mental frameworks and reasoning patterns that power engineering, cybersecurity, programming, and problem solving.

The goal is not just to find answers.

The goal is to understand **how to think**.

---

## Core Principles

- Gather evidence before reaching conclusions.
- Separate facts from assumptions.
- Consider multiple possible explanations.
- Test hypotheses instead of guessing.
- Eliminate possibilities one by one.
- Look for patterns, but verify them.
- Every decision should have a reason.

---

## Engineering Mindset

Observe → Analyze → Hypothesize → Test → Verify → Improve
