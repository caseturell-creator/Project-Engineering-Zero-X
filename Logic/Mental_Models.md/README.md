# 🧩 Mental Models

## What is a Mental Model?

A mental model is a framework for understanding how something works.

Instead of memorizing answers, you understand the underlying system.

---

## First Principles

Break a problem down into its most basic truths.

Ask:

- What do I know for certain?
- What assumptions am I making?
- Can I build the answer from the fundamentals?

---

## Cause and Effect

Every action produces a result.

Examples:

- Bad code → Software bugs
- Weak password → Easier compromise
- High CPU usage → Slower performance
- Strong documentation → Easier maintenance

---

## Systems Thinking

Everything is connected.

Changing one component often affects another.

Example:

User Request

↓

Web Server

↓

Application

↓

Database

↓

Response

If one part fails, the entire system is affected.

---

## Feedback Loops

Outputs become future inputs.

Examples:

- Logs help improve software.
- User feedback improves products.
- Security incidents improve defenses.

---

## Zero X Principle

Understand the system before trying to optimize it.
