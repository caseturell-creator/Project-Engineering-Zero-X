# ✅ Engineering Checklist

Use this checklist whenever you encounter a new problem.

---

# 1. Define the Problem

What is actually happening?

Write the problem in one sentence.

Example:

"The website loads slowly after today's deployment."

---

# 2. Collect Evidence

What do you KNOW?

Examples:

- Error messages
- Logs
- Screenshots
- CPU usage
- Memory usage
- User reports
- Network traffic

Avoid opinions.

---

# 3. Identify Assumptions

What are you assuming?

Examples:

- "It's probably the database."
- "The firewall blocked it."
- "Someone hacked us."

Remember:

Assumptions are not facts.

---

# 4. Build Hypotheses

Create multiple possible explanations.

Example:

Hypothesis A:
Database query is slow.

Hypothesis B:
Web server is overloaded.

Hypothesis C:
DNS is failing.

Never fall in love with your first hypothesis.

---

# 5. Test

Can you prove or disprove each hypothesis?

Use:

- Commands
- Logs
- Monitoring
- Packet captures
- Documentation
- Reproduction

Evidence decides.

---

# 6. Find the Root Cause

Ask:

Why?

Then ask why again.

Keep going until the real cause is found.

---

# 7. Implement the Fix

Fix only what the evidence supports.

Avoid guessing.

---

# 8. Verify

Did the fix actually solve the problem?

Always verify.

---

# 9. Document

Write down:

- Problem
- Cause
- Solution
- Lessons learned

Future you will thank present you.

---

# Zero X Principle

Observe.

Think.

Test.

Verify.

Then act.
