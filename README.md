# Project Engineering Zero

Welcome to **Project Engineering Zero**.

This repository documents my journey from beginner to cybersecurity and systems engineering through structured learning, hands-on labs, and real-world projects.

## Objectives

- Build a deep understanding of computer systems.
- Connect theory with hands-on practice.
- Develop engineering thinking, not just technical skills.
- Create a portfolio that demonstrates consistent growth.

## Repository Structure

- **MIT** – Theory and engineering concepts
- **TryHackMe** – Lab notes and practical exercises
- **Python** – Scripts and automation
- **Projects** – Hands-on builds and portfolio work
- **Cheat-Sheets** – Quick reference guides
- **Engineering-Principles** – Core concepts and lessons learned
- **Journal** – Daily engineering log

## Motto
