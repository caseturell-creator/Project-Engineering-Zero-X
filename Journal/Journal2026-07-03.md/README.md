# Biggest Realizations

## Resource Allocation

A virtual machine does not create new hardware.

A hypervisor allocates physical hardware resources to each virtual machine.

---

## Defaults Have Reasons

Instead of accepting recommended settings, I asked why they existed.

Example:

- Why assign 4 CPU cores?
- Why not 2?
- Why not 6?

The answer is based on workload and maintaining healthy headroom.

---

## Hypervisors vs Containers

Hypervisors run multiple operating systems.

Containers run multiple applications while sharing the host operating system.

The wording of a problem matters.

---

## HTTP Sessions

A cookie is the container.

A session ID is commonly the value stored inside that container.

The browser stores the cookie.

The server recognizes the session ID.
